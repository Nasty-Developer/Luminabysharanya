Build a simple, polished personal productivity web app called LUMINA AI.

The goal is NOT to build a huge complicated AI platform. Keep it lightweight, fast, responsive, and easy to understand.

CORE IDEA

Lumina AI is a personal assistant that helps the user track their daily life in one simple dashboard.

It should feel like a small personal companion that the user can talk to, while also helping them manage daily tasks, habits, notes, and focus sessions.

IMPORTANT:

- I DO NOT have an OpenAI API key or any other AI API key.
- Do NOT require an API key.
- Do NOT build a real external AI integration.
- Create the assistant using local/browser-based logic, predefined responses, simple keyword detection, and stored user data.
- The chat should still feel useful and interactive.
- Everything should work immediately after running the project.

TECH REQUIREMENTS

Use a simple frontend stack:

- HTML
- CSS
- JavaScript
- React is allowed if useful

Keep the project simple.
Do not add unnecessary backend infrastructure.
Do not add Firebase.
Do not add PostgreSQL.
Do not add external AI APIs.
Do not add authentication.
Do not create a complicated admin panel.

Use localStorage for saving tasks, habits, notes, and user preferences.

The application should work entirely in the browser.

LUMINA AI CHAT

This is the main personality feature.

Create a floating Lumina AI chat button.

When clicked, open a clean chat panel.

Header:

"Lumina AI"
"Your personal assistant"

The user should be able to type messages such as:

"Add study to my tasks"
"Remind me to drink water"
"What do I need to do today?"
"How many tasks have I completed?"
"Start a focus session"
"Show my habits"
"I finished my coding task"
"Give me a motivation"
"What's my progress today?"

Since there is NO AI API, create a smart local assistant using JavaScript.

Implement keyword/intent detection.

Examples:

If user says:
"add study to my tasks"

Lumina responds:
"Done. I added 'Study' to today's tasks."

If user says:
"what do I have today?"

Lumina reads the actual task data and responds with today's tasks.

If user says:
"how am I doing?"

Lumina reads the dashboard data and gives a short progress response.

If user says:
"start focus"

Lumina starts the focus timer.

If user says:
"motivate me"

Return one of several predefined motivational messages randomly.

If Lumina does not understand:

"I’m not sure what you mean yet. Try asking me to add a task, check your progress, start a focus session, or show your habits."

The assistant should use the actual application data instead of fake responses.
